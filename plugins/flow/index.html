Flow.

Visual workflow automation with OAuth 2.0 email, conditional triggers, and AI actions — built for Kintone, not bolted on.

Reference & details
The problem

Google killed SMTP. Microsoft is next.

In September 2024, Google removed support for less-secure apps across Gmail. Your Kintone-to-email scripts stopped working. Many teams haven't noticed yet — the scripts fail silently.

In April 2026, Microsoft does the same for Exchange Online and Outlook.com. Basic auth goes dark. Any Kintone integration still using SMTP will break.

The only supported path forward is OAuth 2.0. Which means token refresh loops, consent screens, Azure app registrations, and encrypted credential storage. Not something you want to build yourself.

I.

What Flow does

Six capabilities
01 · Triggers

Five trigger types

Record created, edited, deleted, status changed (process management), and custom button click. Conditional filters on any field.

02 · OAuth email

Gmail & Microsoft 365

OAuth 2.0 with automatic token refresh. Per-user or shared mailbox sending. "Send As" support for Microsoft 365 delegated mailboxes.

03 · Attachments

Per-field file selection

Attach files from any record file field. Choose specific files or attach all. Respects Kintone's file access permissions.

04 · Placeholders

Live record substitution

Use {{field_code}}, {{record_url}}, {{current_user}}. Date formatting. HTML body with Outlook wrapper.

05 · CC & BCC

Multi-recipient

Static lists, field references, or "Load all from app" with the 10k offset limit respected automatically. Edit modal before send.

06 · Actions

More than email

Add comment to record, update field value, cross-app status sync, conditional routing. AI action integration (OpenAI & Claude) on the roadmap.

In practice
We migrated ninety Kintone-to-Gmail automations off SMTP in a single afternoon. The plugin handled every OAuth dance we'd have had to code by hand. — Operations Lead, Manila-based logistics client
