Smart Lookup.

Kintone's lookup modal, redesigned. Full-text search across every field, progressive loading up to 50,000 records, mobile parity.

Reference & details
The problem

The native lookup stops being useful at 500 records.

Kintone's built-in lookup returns 100 rows at a time. It searches one field. On mobile, the UX collapses. In a subtable, good luck. For a master data app with thousands of products, it's unusable.

Smart Lookup replaces the modal entirely. Virtualized scrolling handles 50,000 records without blinking. Search works across every configured field. On mobile, it's the same experience. In subtables, it just works.

We run stress tests on 50k record apps on every release. You can too — the test apps are public.

I.

What Smart Lookup does

Six capabilities
01 · Search

Full-text, multi-field

Search any combination of fields simultaneously. Respects Kintone's filter and sort configuration on the lookup field.

02 · Scale

50,000 records, no lag

Progressive loading with virtual scroll. The modal opens instantly, loads in the background.

03 · Mobile

Parity with desktop

Same features, same speed, on iOS and Android. Kintone mobile app fully supported.

04 · Subtables

Works in sub-tables

Form layout API integration means subtable column order matches your form exactly.

05 · Config

Zero configuration

Reads your lookup field definitions directly. No separate setup UI. Drop it in and it works.

06 · Display

Dense & comfortable

Compact density for power users, comfortable density for everyone else. Toggle per-user preference.
