Capabilities

Search forged in production.

Search every field

No pre-configured "searchable field" list. Every field searchable by default. Customer name, phone number, notes — if it's there, you'll find it.

50,000-record stress tested

Tested at 50k records in real environments. Progressive loading shows the first 20 results while the rest stream in — usable immediately at any scale.

Full mobile parity

Verified on /k/m/ (mobile) URLs. We handle both desktop (button.input-lookup-gaia) and mobile (button.forms-lookup-lookup-gaia) selectors because we actually test on mobile.

Auto-config from field definitions

Reads lookupPickerFields, filterCond, sort, and relatedKeyField directly from Kintone's field definitions. No duplicate configuration in the plugin UI.

Subtable support

Maps DOM subtable render order via Form Layout API. Multiple lookups in multiple subtables don't get confused with each other.

Proven at scale

Running across 43 apps at a Japanese financial group, plus manufacturing, NGO, and logistics clients. Over 100 apps in production total.
