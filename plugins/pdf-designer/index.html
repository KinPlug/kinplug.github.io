PDF Pro.

A proper PDF designer for Kintone. WYSIWYG templates, expression engine, multi-page layouts, Japanese fonts included.

Reference & details
The problem

Kintone exports look like it's 2005.

Export to PDF from Kintone and you get the raw record view — every field, every label, in whatever order your form builder dropped them. Not a document you send to a customer. Not an invoice. Not a quote.

So teams build workarounds. Export CSV, open Excel, reformat, save as PDF. Or hire a developer to write custom JavaScript. Or just accept the ugliness.

PDF Pro is the third option: a visual template designer that produces real documents from your records. Headers. Footers. Subtable loops. Expression-evaluated fields. Inline charts. In any language.

I.

What PDF Pro does

Six capabilities
01 · Designer

WYSIWYG layout

Drag-and-drop a real document. Text, images, lines, tables. Positioned in millimeters, not CSS approximations.

02 · Expressions

Formula engine

{{subtotal * 1.10}}, conditional logic, date math, text manipulation. If Excel can do it, we can.

03 · Subtables

Row loops

Subtable rows render as repeating bands with running totals, page-break awareness, and alternating row styles.

04 · Charts

Inline visuals

Bar, line, pie — plotted from record data at render time. No external chart service, no flicker.

05 · Multi-page

Headers & footers

Page numbers, running titles, per-section headers. A2 through envelope size. Landscape or portrait.

06 · Fonts

Japanese out of the box

Noto Sans JP, Noto Serif JP, IPA Mincho, IPA Gothic bundled. Upload custom fonts too.

Representative output
Our old template pipeline was a Python script on a separate server. PDF Pro replaced it and made the templates editable by the operations team. Huge. — IT Lead, Tokyo manufacturing group
