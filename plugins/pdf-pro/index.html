Capabilities

Beyond simple variable substitution.

Expression engine

Conditional branches, subtotals, currency formatting, tax computation — real logic inside templates. Not the simple mail-merge that competitors ship.

Multi-page + table splitting

Automatic pagination when line items overflow, repeating headers/footers, multi-quote-per-PDF output. Handles contracts with attached specs and long-form documents.

Inline charts

Bar, pie, and line charts embedded directly in the PDF. No external tools, no image stitching — monthly reports and sales summaries render cleanly in one pass.

Japanese fonts bundled

Noto Sans JP, Noto Serif JP, IPA fonts shipped with the plugin. Japanese qualified invoice (適格請求書) template formats supplied out of the box.

All configuration inside Kintone

Design, save, update — all inside the Kintone plugin settings UI. No external portal. We split configs across Kintone's 65,535-character limit automatically when templates grow.

Automated output

Combined with Kinplug Mail: approval triggers invoice generation → PDF attached → email sent → field updated. End-to-end without gluing services together.
