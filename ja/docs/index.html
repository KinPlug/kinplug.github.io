ドキュメント。

インストールガイド、APIリファレンス、トラブルシューティング。プラグイン別に整理。

01

ご利用開始

5分で · ゼロから

1. kinplug.comでサインアップ。Google / Microsoft SSO、またはメール。カード不要。

2. トライアル開始。ダッシュボードからKintoneサブドメイン（.kintone.comの前の部分）を入力。

3. ライセンスキーをコピー。KP-XXXX-XXXX-XXXX形式。

4. プラグインをアップロード。Kintoneのシステム管理 → プラグイン → 新規から最新zipをアップロード。

5. アプリに追加。アプリ設定 → プラグイン → プラグインの追加からライセンスキーを設定。

02
