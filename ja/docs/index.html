プラグインのインストール方法

  1. プラグインファイルをダウンロード - トライアル開始後または購入後、ダッシュボードから.zipファイルをダウンロードします。
  2. kintone管理画面を開く - 歯車アイコン → kintoneシステム管理 → プラグイン。
  3. プラグインをアップロード - 「プラグインの追加」をクリックし、.zipファイルをアップロードします。
  4. アプリに追加 - アプリの設定 → プラグイン → プラグインを追加。
  5. 設定 - プラグインの設定を開き、ライセンスキーを入力します。
  6. 適用 - 「アプリを更新」をクリックしてプラグインを有効化します。

ライセンスの有効化

  1. ダッシュボードまたはウェルカムメールからライセンスキーをコピーします。
  2. kintoneアプリを開く → 設定 → プラグイン。
  3. KinPlugプラグインの歯車アイコンをクリック。
  4. 「ライセンスキー」フィールドにライセンスキーを貼り付けます。
  5. 「保存」をクリックしてアプリを適用します。

💡 1つのライセンスで、同じkintoneサブドメイン内のすべてのアプリで使用できます。

無料トライアルの開始

  1. kinplug.com/loginでアカウントを作成します。
  2. ダッシュボードを開きます。
  3. 試したいプラグインの「トライアル開始」をクリックします。
  4. kintoneサブドメインを入力します（例：mycompany.kintone.comの場合は「mycompany」）
  5. トライアルライセンスキーをコピーしてkintoneで使用します。

💡 トライアルは14日間、全機能利用可能。クレジットカード不要です。
