Kinplug Dashboard

アプリをまたいで、ひとつのダッシュボードに。

kintone の集計は、ひとつのアプリの中で完結してしまいます。売上アプリと目標アプリ、実績と予算 — 別々のアプリにあるだけで、比較するには CSV に落とすしかない。Kinplug Dashboard は共通キーでアプリ同士を並べて比較し、複数アプリの行をまとめて集計します。アプリの構造は変更しません。

30日間無料で試す→ 料金を見る

日付とドロップダウンが、そのまま噛み合う

売上アプリの受注日は日付フィールド、目標アプリは「FY2025」「Q1」のドロップダウン — 本来なら揃わない組み合わせです。Kinplug Dashboard は日付を年度・四半期・月に変換して自動で対応付けます。年度は4月開始が既定（変更可）なので、2025-05-02 は Q1・FY2025 として扱われます。予実管理がデータ移行なしで成立します。

外部サーバーに、データを出しません

集計はすべてブラウザ内で、閲覧しているユーザー自身の kintone 権限で実行されます。データを預かる外部サーバーはありません。見えないはずのレコードは、ダッシュボードでも見えません — kintone のアクセス権がそのまま効きます。稟議・情報システム部門の確認が通りやすい構成です。

  • 42種類のグラフ（棒・折れ線・複合・ヒートマップ・ガント・カレンダー・ピボットほか）
  • 万・億の単位表示、日本語UI（翻訳ではなく日本語で設計）
  • ダッシュボードは kintone のレコードとして保存 — 共有は権限設定そのまま
  • ページ（タブ）で1つのダッシュボードに複数画面

krewDashboard との比較

メシウス社の krewDashboard は、この分野で実績のある優れた製品です。どちらも kintone スタンダードコース以上が必要で、30日間の無料試用があります。公開情報で異なる点は次のとおりです。

  • 料金体系 — krewDashboard シンプルエディションは月額 ¥12,000／ドメイン（年額 ¥120,000）と公開されています。Kinplug Dashboard は単体課金ではなく、Kinplug のサブスクリプションにすべてのプラグインが含まれます。
  • データの処理場所 — 集計はブラウザ内で閲覧ユーザーの kintone セッションで実行されるため、誰に何が見えるかは kintone のアクセス権がそのまま決めます。
  • 期間の対応付け — 日付フィールドと「FY2025」「Q1」のドロップダウンを自動で突き合わせます（既定は4月開始の年度）。

上記の他社価格は執筆時点でメシウス社・サイボウズ社が公開している情報です。最新の金額は各社サイトをご確認ください。
