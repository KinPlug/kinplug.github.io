機能

メール送信と自動化が、ひとつに。

認証
OAuth 2.0完全対応

Gmail（Workspace含む）およびMicrosoft 365（Exchange Online）のOAuth 2.0対応。SMTPパスワードを保存しないため、各社の認証変更の影響を受けません。トークン自動更新対応。

送信者
Send Asと共有メールボックス

Microsoft 365のExchange Admin権限委譲を使った正規のSend As送信。個人メールボックスからの代理送信、共有メールボックスからの送信、両方に対応。

自動化
ビジュアルフロー

「レコード追加時」「ステータス変更時」「日時指定」などのトリガー、条件分岐、複数アクション連鎖をGUIで設計。Zapier/Make相当の自動化がKintone内で完結します。

添付
フィールド単位の添付選択

添付ファイルをフィールド単位で指定可能。「見積書フィールドのPDFのみ添付、内部資料は除外」といった細かい制御ができます。PDF Proで動的生成したPDFの添付にも対応。

一括送信
10,000件超の一括対応

一覧画面から条件指定での一括送信に対応。Kintone APIの10,000件オフセット制限を回避する独自実装で、大規模一斉送信も1クリックで完了。送信ログはKintoneアプリに保存。

予約送信
タイムゾーン対応スケジュール

日時指定送信、ルール化予約（「毎月1日」「金曜17時」等）、重複実行防止ロック機構。タイムゾーン意識した設計で、JST環境・Global環境どちらでも正確に動作。

導入

既存プラグインからの移行も、90秒で。

Kinplug Mailのインストールは、Kintoneのプラグイン管理画面から.zipをアップロードして、OAuth認証を1回だけ行うだけです。既存のメールプラグインから移行する場合も、テンプレート・宛先ロジック・送信者設定を保持したまま切り替えられます。

30日間のトライアル中に、実際の環境でそのまま検証していただけます。稟議書や契約書類が必要な場合は、お問い合わせフォームから必要な書類をお知らせください。

kMailer との比較

トヨクモ社の kMailer は kintone 連携メールの定番製品で、HTML メール作成・開封率分析・A/B テストなど配信施策に強い製品です。メールマーケティングが主目的であれば有力な選択肢です。業務メールでは、構造上の違いが効いてきます。

  • どこから送信されるか — Kinplug Mail は OAuth 2.0 で認証し、自社の Gmail / Microsoft 365 メールボックスから送信します（Send As・共有メールボックス対応）。返信は同じメールボックスに届き、送信済みトレイにも残ります。
  • 料金 — kMailer はスタンダード月額 ¥15,000、プレミアム月額 ¥24,000 と公開されています。Kinplug Mail は単体課金ではなく、Kinplug のサブスクリプションに全プラグインが含まれます。
  • 認証方式の期限 — Gmail は2024年に基本認証を終了、Microsoft も Exchange Online で廃止を進めています。パスワード方式の kintone メールカスタマイズは動作しなくなり、OAuth 2.0 が正式な移行先です。

上記の他社価格は執筆時点でトヨクモ社が公開している情報です。最新の金額は同社サイトをご確認ください。
