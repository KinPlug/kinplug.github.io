Getting started

Five minutes · From zero

1. Sign up at kinplug.com. Google or Microsoft SSO, or email. No credit card.

2. Start a trial from your dashboard. Enter your Kintone subdomain (the part before .kintone.com).

3. Copy your license key. It looks like KP-XXXX-XXXX-XXXX.

4. Upload the plugin to Kintone via System administration → Plugins → New. Download the latest .zip from your dashboard.

5. Add the plugin to any Kintone app via App settings → Plugins → Add plugin, then configure with your license key.
